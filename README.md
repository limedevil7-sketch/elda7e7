# ويبسايت الدحيح

موقع عربي متجاوب لطلاب السنة الأولى بكلية الحقوق، جامعة المنوفية. أصبح قسم الأسئلة يستخدم Cloud Firestore لعرض الأسئلة والردود نفسها لجميع الزوار، مع تحديث مباشر.

## تفعيل Firebase

1. من Firebase Console للمشروع `elda7e7-f497b`، فعّل **Authentication → Anonymous**.
2. أنشئ قاعدة **Cloud Firestore** واختر موقع الاستضافة المناسب.
3. من مجلد `outputs` شغّل Firebase CLI وسجّل الدخول، ثم نفّذ: `firebase deploy --only firestore:rules,hosting`.
4. افتح الموقع من رابط Firebase Hosting. للمعاينة المحلية استخدم خادمًا على `http://localhost`؛ فتح `index.html` مباشرة عبر `file://` لا يشغّل وحدات Firebase.
5. سجّل الدخول إلى الموقع بحساب الإدارة `lime_devil`. ستعرض لوحة الإدارة معرّف Firebase الخاص بالمتصفح. في Firestore Console أنشئ مستندًا في مجموعة `admins` يكون اسمه هذا المعرّف، وأضف الحقل `active` من النوع Boolean وقيمته `true`. بعد إعادة تحميل الصفحة يمكن لهذا الحساب نشر الردود وحذف الأسئلة المشتركة.

القواعد موجودة في `firestore.rules`، وإعداد الاستضافة في `firebase.json`. لا تفتح صلاحيات الكتابة العامة في قواعد Firestore؛ القواعد المرفقة تسمح بإنشاء الأسئلة للمستخدمين المسجلين مجهولًا، وتجعل الرد والحذف مقتصرين على معرّف الإدارة المفعّل.

## حدود النسخة الحالية

- Firebase يحفظ الأسئلة العامة والردود، ويزامنها بين الأجهزة.
- تسجيل أسماء المستخدمين الحالي وحساب `lime_devil` ما زالا تجريبيين ومحليين في المتصفح. Firebase Anonymous Auth يثبت جلسة المتصفح فقط؛ انقل حسابات الطلاب إلى Firebase Authentication قبل إطلاق عام حتى تثبت هوية صاحب كل سؤال.
- الرسائل الخاصة في «سؤال لمنشئ الموقع» وملفات PDF ما زالت محلية في المتصفح، ولا تتزامن بين الأجهزة. نقلها يتطلب Firestore/Cloud Storage وقواعد وصول منفصلة.
- إعداد Firebase يحمّل SDK من CDN، لذلك يحتاج الموقع إلى اتصال إنترنت وفتح عبر HTTP/HTTPS.
