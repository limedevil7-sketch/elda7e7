# ويبسايت الدحيح

موقع عربي متجاوب لطلاب السنة الأولى بكلية الحقوق، جامعة المنوفية. يضم مواد الدراسة، أسئلة مشتركة، ولوحة إدارة المحتوى.

## الملفات المرفقة

- `index.html`: الواجهة والتصميم والتفاعلات، ويحمّل `firebase.js`.
- `firebase.js`: اتصال Firebase للأسئلة، واتصال Supabase لملفات PDF.
- `firebase.json` و`firestore.rules`: إعداد Firebase Hosting وقواعد Firestore للأسئلة.
- `supabase-setup.sql`: إنشاء جدول ملفات الدراسة وسياسات قراءة الملفات ورفعها وحذفها.

## إعداد Supabase للملفات

1. أنشئ bucket باسم `elday7e7` واجعله **Public** حتى يتمكن الطلاب من فتح روابط ملفات PDF.
2. شغّل `supabase-setup.sql` من **SQL Editor**. إذا كنت قد شغّلته والسياسات ظهرت بنجاح، لا حاجة لإعادته الآن.
3. من **Authentication → Users** أضف حساب المسؤول `limedevil7@gmail.com` واختر كلمة مرور قوية، واجعل البريد مؤكدًا.
4. في الموقع سجّل الدخول باسم المستخدم `lime_devil` وكلمة المرور التي وضعتها لحساب Supabase. صلاحية الرفع والحذف تتحقق من جلسة Supabase والسياسات، ولا تعتمد على إظهار اللوحة وحده.

الموقع يستخدم المفتاح العام Publishable Key داخل `firebase.js`، وهذا المفتاح مخصص للواجهة. لا تضع أبدًا Secret أو service_role key في ملفات الموقع أو GitHub.

## إعداد Firebase للأسئلة والردود

1. في مشروع Firebase `elda7e7-f497b` فعّل **Authentication → Anonymous** وأنشئ قاعدة **Cloud Firestore**.
2. انشر محتوى `firestore.rules` من تبويب Rules في Cloud Firestore، أو باستخدام Firebase CLI بعد اختيار المشروع: `firebase deploy --only firestore:rules`.
3. بعد دخول مسؤول الموقع إلى النسخة المنشورة، تعرض لوحة الإدارة Firebase UID. أنشئ في Firestore مستندًا داخل مجموعة `admins` واسمه UID نفسه، مع `active` من النوع Boolean وقيمته `true`، لتفعيل ردود وحذف أسئلة النقاش.

ملفات PDF وبياناتها تُحفظ في Supabase. الأسئلة والردود العامة تُحفظ في Firestore. رسائل «سؤال لمنشئ الموقع» وحسابات الطلاب التجريبية ما زالت محلية في المتصفح، لذلك لا تتزامن بين الأجهزة.

## النشر على GitHub Pages

ارفع `index.html` و`firebase.js` و`README.md` وملفات الإعداد إلى جذر الفرع الذي يستخدمه GitHub Pages. انتظر اكتمال النشر ثم حدّث الصفحة تحديثًا قويًا بـ `Ctrl+F5`. يجب فتح الموقع من HTTPS؛ فتح HTML مباشرةً عبر `file://` لا يشغّل وحدات JavaScript الخارجية.

`firebase.json` موجود أيضًا لإعداد Firebase Hosting، لكن GitHub Pages لا يقرأه. ملفا `.firebaserc` و`.gitignore` غير مرفقين في الحزمة بناءً على طلب صاحب الموقع.

## المزايا الحالية

- واجهة عربية RTL متجاوبة للكمبيوتر والهاتف، بتصميم قانوني داكن ولمسات ذهبية وحركات خفيفة.
- المواد الدراسية الخمس ونافذة عرض الملفات وفتح PDF.
- أسئلة ونقاشات مشتركة، وردود الإدارة عبر Firebase.
- رفع PDF للجميع وحذفه عبر Supabase Storage؛ الحد داخل الواجهة 25 ميجابايت.
- زر تواصل واتساب مع العرباوي، وحقوق صنع الموقع في التذييل.
